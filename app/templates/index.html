Sistema de visualizacao dos CONTRATOS PUBLICOS 2024

Esta plataforma foi desenvolvida no contexto da unidade curricular de **Base de Dados**, no ano letivo 2025/2026, com o objetivo de fornecer uma visão clara e detalhada dos dados de **Contratos Públicos**. A partir do ficheiro `ContratosPublicos2024.csv`, foi modelada uma base de dados que segue a **Terceira Forma Normal (3FN)** para garantir a integridade e a eficiência na consulta dos dados. Utilize o menu de navegação para aceder a relatórios estatísticos, análises detalhadas e à estrutura completa da base de dados.
